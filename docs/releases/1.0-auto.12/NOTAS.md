# Puchamon: Origins 1.0 · auto.12

Corrección del bloqueo por hashes después de guardar FTB Quests. Los 23 capítulos se distribuyen en el formato escrito por la propia versión instalada de FTB Quests y se ha probado su guardado, recarga y segundo guardado sin cambios de bytes. Se mantiene la verificación SHA-256 estricta y se conserva el launcher instalado; la corrección llega al pulsar Jugar, sin reinstalar ni ejecutar otro BAT.

No cambia el contenido funcional de las misiones, sus identificadores, requisitos ni recompensas. No se sustituye progreso de jugadores, mundos, Pokémon, inventarios, tumbas, Lootr, homes, cuentas, mapas, waypoints ni preferencias personales. No se añade Super Firework ni ningún mod nuevo.

El servidor debe exigir puchamon-1.0-auto.12 mediante puchamon/release.json y reiniciarse para releer ese marcador. El overlay mínimo solo contiene ese archivo. No copiar el directorio server completo para este parche.
