# Puchamon: Origins 1.0 · auto.13

Añade Dis-Enchanting Table 5.0.2 y MonoLib 4.1.2 desde sus descargas oficiales. Mesa manual: cinco niveles de Minecraft por operación, conserva durabilidad y penalización del yunque, sin automatización. Incluye nombres en español y un nodo informativo sin recompensa en Comodidad y almacenamiento. Todos los identificadores, requisitos y premios previos se conservan. No cambia mundos, cuentas, Pokémon, inventarios, tumbas, homes, mapas, waypoints, controles ni preferencias.

Despliegue: usar solamente el overlay mínimo preparado para auto.13; los dos JAR se obtienen de disenchanting-downloads.json, no se redistribuyen aquí. Reiniciar para activar mods y exigir puchamon-1.0-auto.13.
